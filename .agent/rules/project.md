# 《江湖仙途 · 雙生天命》專案規範

1. **語言規範**：
   - 全程使用**繁體中文**回覆與撰寫遊戲文本。

2. **打包、版本號與提交流程**：
   - 每次修改 `index.html`、`data.js` 或 `patches.js` 後，必須同步重新打包單頁行動版 `jhst_mobile.html`（內嵌 `data.js` 與 `patches.js`，但不內嵌 `bgm/` 音樂檔以保持檔案輕量）。
   - 同步更新版本號（格式 `vYYYY.MM.DD.HHMM`）。
   - 驗證 JavaScript 語法無誤後，執行 `git commit` 提交變更。

3. **協作與設計討論原則**：
   - 每次使用者提出建議或想法時，若有想到更好的設計方式、體驗優化或潛在問題，請主動提出討論，不必完全照單全收。
